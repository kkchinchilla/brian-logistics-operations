# Increment 1.4.63 — 日期導覽統一為單列獨立按鈕

依使用者要求，日期導覽統一採用司機版的獨立上一日／下一日按鈕，
並讓兩個箭頭與中間的日期欄位維持同一列。

## 範圍

- 每日出勤：司機、主管與管理員。
- 月度報表：有權限帳號的月份導覽採用相同樣式。
- 公司與展示環境使用同一份樣式。
- 移除 380px 以下將日期放在第一列、箭頭放在第二列的舊規則。
- 兩側按鈕至少 44px，保留原生日期／月份選擇器、焦點與操作邏輯。
- 路線管理、車輛管理及帳號管理沒有此類頁面日期導覽，不新增控制項。

## 驗證與驗收

- 執行 build、check、既有應用測試、schema 還原與展示封裝檢查。
- 檢查五份頁面引用；除了樣式版本，其餘頁面內容不變。
- 特別比對路線模板：其篩選器、頁尾與導覽樣式未變。
- 本次瀏覽器環境無法啟動；手機實際版面尚待使用者確認。
- 手機驗收：以各角色檢查前一天／日期／後一天維持同列、日期可讀且可開啟選擇器；
  管理員另檢查月報的上個月／月份／下個月。檢查直向、橫向及放大系統文字。

不需資料庫 migration。還原本次 CSS 與五頁的樣式引用版本即可回復版面。
