# 四大 Dashboard — UI/UX 還原與響應式修正版

本版以使用者定稿的四份原型為參考，**只更新 HTML/CSS/前端呈現方式**，並保留整合版已在使用的 Supabase 資料查詢、登入和資料庫結構。沒有虛構展示資料，沒有任何需要重跑的 SQL。

## 部署

1. 先備份目前已連線成功的專案資料夾。
2. 將更新 ZIP 解壓縮至 `dispatch-system-v0.5.5` 的**上一層**，合併檔案。
3. **不要覆蓋**你現有的 `js/config.js`。本增量更新包根本不包含它。
4. 重新整理網站；若 CSS 被瀏覽器快取，請強制重新整理（Mac：Command+Shift+R；Windows：Ctrl+Shift+R）。
5. 使用現有帳號從 `index.html` 登入，確認四頁都仍能讀取既有資料。

## 本次 UI 改善

- **每日出勤**：恢復雙層溫層分組表頭、趟次及車號配對、固定司機姓名欄、空白格不顯示假資料。依資料當日趟數動態產生欄位；日期切換、原定任務、實際用車更新與結案使用原先接口。
- **路線管理**：保留原型的四張摘要卡、費率表、地區／溫層、右側編輯面板；移除多餘預覽開關、浮動登入按鈕和雙重導航。仍使用原先 `ui-routes-live.js` 的 Supabase 正式讀寫。
- **車輛管理**：依原型增加「車輛與綁定／司機名單」兩個操作視圖，保留既有新增車輛、綁定、改名流程。移除手動租車判定 Tab。
- **月度報表**：四張摘要卡、橫向捲動的統計矩陣，點擊司機以側邊抽屜／手機底部明細檢視與修改加給、獎懲。計算仍使用既有已確認紀錄，未有正式薪資規則的薪資仍顯示「待設定」。
- **共通 CSS**：黃色 `#ffda36`、午夜灰、無漸層；桌面側邊導覽、手機底部導覽；表格只在容器內橫向捲動。觸控編輯視窗不再超出畫面。沒有頭像與重複權限標籤。

## 不變的功能邊界

本次是外觀及操作布局的增量修正，不補上尚未開發的業務功能：例如從每日空白格直接新增派車、跨司機替班一鍵更新、月報完整正式薪資公式、舊系統與日終結案全面鎖定，仍維持上一版既有的功能限制。可從舊版頁面處理已存在的特殊勤務。

## QA 說明

- 以隔離式、**僅供瀏覽器測試的暫時資料**執行 4 頁 × 6 種視窗寬度（320、375、768、1024、1366、1920px）共 24 組版面檢查。
- 驗證表格橫向捲動不撐開整頁、路線編輯面板、車輛司機名單切換、實際用車編輯後標示、月報明細抽屜及編輯對話框，瀏覽器 JavaScript 例外為 0。
- 暫時資料只存在於本次測試程式中，**未寫入更新包或你的 Supabase**。
- 由於沒有直接連線至你的 Supabase，實際資料庫寫入及 RLS 仍需要在你已部署的環境進行回歸驗收。

## 建議回歸測試

1. 管理員登入，四頁原有資料顯示正確。
2. 每日出勤選擇有趟次的日期、用司機帳號修改本人實際車號、主管結案（建議先用可回復的非營運日期測試）。
3. 路線管理編輯一條可安全修改的測試路線，重新整理後值仍在。
4. 車輛管理切換兩個 Tab，開啟車輛與司機的編輯面板，保留已有綁定紀錄。
5. 月度報表點選司機打開明細；確認仍能查看已確認趟數，所有薪資加給及獎懲紀錄未變動。
6. 在手機／平板／桌面實機檢查表格滑動、抽屜與底部導覽。

任何頁面顯示不符原型時，請提供頁面、螢幕寬度、目前畫面截圖與對應原型畫面，我們可以逐項做到視覺驗收。
