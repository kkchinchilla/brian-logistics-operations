# 四大 Dashboard UI/UX 對版調整 — Pass 2

日期：2026-10-18  
對照基準：本次收到的四份定稿 HTML prototype（原始 `Archive.zip`）。

## 修改內容

1. **每日出勤（Daily_Attendance_Dashboard_v2）**：恢復頁首日期切換與結案操作列；黃色異動圖例；分組溫層／車號雙層欄頭、司機固定欄與底部統計。保留原定車號與實際車號編輯，結案權限沿用正式後端。
2. **路線管理（route-management-interactive-prototype-v2）**：原型路線卡片、列表、費率表與右側編輯面板延續；正式頁面移除重複頂部導航和展示入口，修復正式資料狀態提示；手機改為四頁可操作導覽，不再固定原型 394px 寬度。
3. **車輛管理（vehicle-management-interactive-prototype-v2）**：調整為「自有車司機／已綁定車輛／未綁定車輛」三項真實統計；將新增車輛移至頁首；保留車輛與綁定／司機名單分頁以及日期生效綁定。
4. **月度報表（Monthly_Report_Dashboard_v3_1_Amount_Label_Fixed）**：頁首月份切換與匯出、月度總覽／計價設定分頁、司機排序、統計矩陣；加上司機明細抽屜內的「薪資明細／每日出勤」切換。正式薪資參數不足的項目維持「待設定」，不填入示範薪資。
5. **共通**：同一深灰＋黃色系、頁首層級、左側四頁導覽、手機底部導覽；表格只在自身區域橫向捲動，編輯對話框可捲動。

## 不更動的部分

- Supabase 專案、資料表結構、SQL、登入流程與資料權限。
- `js/config.js` **不在此更新包內**；保留目前已連線成功的設定。
- 不附任何假資料／不匯入展示資料／不修改既有正式出勤、薪資或車輛紀錄。
- 原先尚未串接的操作，如每日出勤直接調整每人趟數、完整計薪公式、所有計價設定的可編輯矩陣，**本次沒有冒充已完成**。計價設定目前是唯讀資料摘要。

## 安裝（適用先前的 integrated-no-demo-v1、responsive-full 或 pass1）

1. **先備份**整個已能登入並讀取資料的 `dispatch-system-v0.5.5` 資料夾。
2. 將 `dispatch-ui-parity-pass2-upgrade.zip` 解壓縮至 `dispatch-system-v0.5.5` **上一層**，選擇「合併／覆蓋同名檔」。勿把 ZIP 解壓在專案內再產生巢狀資料夾。
3. **不要覆蓋或刪除**現有 `js/config.js`。更新包不含此檔。**不需要跑任何 SQL。**
4. 從目前的 `index.html` 登入後檢查 `ui-attendance.html`、`ui-routes.html`、`ui-vehicles.html`、`ui-monthly.html`。
5. 強制重新整理快取：macOS `⌘ + Shift + R`；Windows `Ctrl + Shift + R`。

若使用 `dispatch-system-ui-parity-pass2-full-no-config.zip` 做全新部署，請由舊專案備份**單獨補回**你原本的 `js/config.js`；不要用範例 key 取代正式設定。整包內含既有版本的 SQL 檔案僅作原始專案保留，**本次不需執行**。

## 已執行的離線 QA

- 使用與正式資料隔離的本機臨時 JavaScript 模擬資料，檢查 4 頁 × 6 個寬度（320 / 375 / 768 / 1024 / 1366 / 1920px），共 **24 組**。
- 24 組均無未處理的瀏覽器 JavaScript exception，且頁面根層無水平溢出。
- 額外驗證車輛「司機名單」切換、月報「計價設定」切換、月報司機抽屜「每日出勤」切換。
- 模擬資料只用於 QA，**不包含在 ZIP 內**，未連線或寫入你的 Supabase。
- 尚未在你的實際 Supabase 帳號上驗證 RLS／資料回寫；更新後須在可回復的測試紀錄上做一次回歸驗收。

## 建議線上驗收

- 每日出勤：日期切換、不同溫層的實際趟數、自有車與租車顯示、主管結案與重新開啟。
- 路線管理：路線列表、費率表、地區／溫層、新增與編輯路線（先測非營運資料）。
- 車輛管理：車輛名單、司機名單、綁定有效日期與既有歷史。
- 月度報表：已確認趟次、值班與租車統計、CSV、薪資加給／獎懲編輯，以及明細中的每日出勤。
- 使用桌機及手機各檢查一次彈窗、水平捲動與底部導覽。若現場資料與 UI 原型不符，先記錄頁面／視窗寬度／異常欄位，不要直接改動正式薪資設定。
