# Increment 1.4.4 — 車輛綁定與自動租車判定

## 適用基線
Increment 1.4.3 完整版，包含 143 SQL。資料庫 migration `increment_144_auto_rental_and_multi_driver_bindings` 已於開發專案 dispatch-system-dev 執行成功。

## 業務規則
- 綁定為長期關係，自生效日起持續有效，直到主管設定結束日。
- 同一司機可綁定多輛車；同一輛車可同時綁定多名司機。
- 同一組司機／車輛不可有重疊期間。
- 在每日出勤、新增配送趟次以及單日班表編輯時，預帶該司機在配送日期有效綁定的車號，仍可修改。
- 同一天若有多個綁定候選，系統預選最近生效日、同日以車號 ID 排序第一筆；使用者仍可改選其他車輛。
- 未綁定的車輛可選，但儲存時由 SQL 自動記錄租車。若綁定則為非租車。
- 無日期的範本不儲存租車狀態；套用至指定日期的 runs 由 SQL 依當日關係判斷。
- 已確認完成紀錄與既有趟次的歷史租車標記不因這次更新而被重算。
- 原本的司機、車輛、路線與時間衝突檢查仍有效；同一車有多名綁定司機不表示可同時出車。

## 安裝
1. 更新前端，保留現有 `js/config.js`。
2. DB migration 已執行，**勿重複盲目執行** `sql/144_01_auto_vehicle_binding.sql`。如部署另一環境，先檢查 schema 再執行。
3. 開啟 UI、清除快取或強制重新整理。
4. SQL `144_02_verify_readonly.sql` 可單獨再驗證部署狀態。
