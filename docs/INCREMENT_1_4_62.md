# Increment 1.4.62 — 手機版司機名單欄寬

車輛管理的「司機名單」只有三欄，卻沿用寬表格的手機最小寬度，
導致固定的司機姓名欄過寬，壓縮其餘欄位的可視範圍。

## 調整

- 800px 以下的司機名單改為符合容器寬度的固定欄寬表格。
- 姓名欄占 32%；車輛數欄依文字大小保留空間；其餘分配給綁定車號。
- 長姓名與多筆車號可換行，完整保留文字。
- 新增表格視圖標記及此頁專用樣式；公司與展示版本共用修正。
- 桌面版、車輛與綁定表格、權限與業務邏輯不變。

## 驗證

- 通過 build、check、既有應用程式測試、可攜式 schema 還原與展示版本封裝測試。
- DOM 檢查涵蓋搜尋、無資料、切換頁籤與視圖標記；修改姓名視窗與司機存取限制保留。
- 瀏覽器執行環境無法啟動，未完成像素層級或實機版面驗收。

## 手機驗收

1. 更新 App，以有車輛管理權限的帳號開啟「司機名單」。
2. 確認姓名、綁定車號與車輛數三欄可讀；長內容完整換行。
3. 檢查窄螢幕、橫向與放大系統文字；切換回「車輛與綁定」確認原版面。
4. 檢查搜尋、無結果、編輯司機及展示環境標示。

不需資料庫 migration。回復時一併還原此專用 CSS、HTML 引用與 JS 視圖標記。
