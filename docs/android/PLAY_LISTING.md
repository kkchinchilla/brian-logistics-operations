## Short description

掌握配送排班與每日出勤，整合路線、車輛及月度對帳，讓司機與管理人員同步工作資訊。

## Full description

貨易通是供物流團隊使用的配送與出勤管理工具，讓司機、主管與管理員依各自權限，透過手機或網頁查看工作資訊。

【司機查看自己的工作】
以手機號碼及密碼登入，查看自己的配送路線、車輛、勤務與備註。手機採直向卡片呈現，方便查閱；司機不能修改排班。

【主管安排每日出勤】
管理配送趟次、路線、車輛及值班、跟車、學習紀錄，支援單日範本與批次排班。結案後可供月度對帳；重新開啟及確認結案後，更新報表所使用的紀錄。

【管理員核對月度資料】
獲授權的管理員可設定配送與勤務費率、核對租車費用及加給／獎懲，查看司機月度統計與應計薪資，並匯出 CSV。

【同一套資料，跨裝置使用】
手機 App 與網頁連接同一套系統，依帳號權限顯示資料。使用時需要網路連線；連線中斷時會提示重試。

本服務需要由團隊管理員建立帳號，下載 App 不會自動取得團隊資料的存取權限。各功能依帳號角色開放。
